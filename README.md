## 一、项目简介

VIV 健康平台 App 是 VIV 智能按摩设备的官方配套应用。产品以 **「设备控制 + 健康数据」双核心** 切入，打通「配对连接 → 按摩控制 → 手法商城 → 健康报告」全链路，解决智能硬件「卖出去了、价值却没用起来」的行业共性问题。

产品不做大而全的平台化堆叠：V1.0 克制地收敛为工具型产品，把 **连得上、控得好、看得见数据** 三件事做到极致；手法商城与 OTA 作为内容供给，持续延长硬件生命周期。

---

## 二、核心能力

| 能力 | 说明 |
|---|---|
| **设备遥控** | 蓝牙接管模式、力度（1–9 档）、热敷、时长全部控制能力，指令端到端延迟 ≤300ms；断连自动停机保护 |
| **极速配对** | 长按电源键进入配对模式 → 扫描 → 鉴权绑定，平均 15 秒完成，配对成功率 ≥98% |
| **内容供给** | 手法商城浏览/下载/蓝牙同步至设备，「我的手法」一键运行，让硬件持续获得新玩法 |
| **健康管家** | 使用记录自动沉淀，日/周/月趋势图表与每周放松报告，让「坚持使用」被看见 |
| **多端一致** | 使用数据本地缓存、断网不丢，恢复后按时间戳去重补传，云端与端侧保持一致 |

## 三、产品指标体系

| 层级 | 指标 | 目标值 |
|---|---|---|
| 激活 | 设备配对成功率 | ≥ 98% |
| 激活 | 新手完成率（24h 内首次 ≥5 分钟按摩） | ≥ 70% |
| 使用 | 设备周使用次数 | ≥ 4 次 |
| 使用 | App 控制占比 | ≥ 60% |
| 留存 | 绑定用户 30 日留存 | ≥ 45% |
| 内容 | 手法下载渗透率 | ≥ 30% |
| 质量 | 崩溃率 / ANR 率 | ≤ 0.1% / ≤ 0.05% |

> **北极星指标**：周有效按摩设备使用次数（单次 ≥5 分钟计为有效）—— 衡量「硬件被真正用起来」的核心价值。
